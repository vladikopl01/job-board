# Motion audit

Audited 2026-11-11. Scope: application shell, collections, posting reader, selection dock, command popovers, forms, and refresh feedback. [Original implementation plan](001-immediate-collection-navigation.md); [latest collection review](../plans/004-collection-controls.md). The original plan's tab and inline-reader decisions are superseded by the screenshot-requested Select and overlay Sheet.

| Category             | Disposition                                                                                                                                                                                                             |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Purpose/frequency    | Sidebar and collection layout changes are immediate, including keyboard toggles.                                                                                                                                        |
| Easing/duration      | Reader Sheet entry takes 200ms. Content fades/rises over 180ms, with 0/40/80ms group delays (260ms total), using cubic-bezier(.23,1,.32,1). Retain the 180ms completion pulse.                                          |
| Physicality/origin   | Preserve installed anchored-popup behavior. The requested reader Sheet enters from its right edge; Previous/Next change content immediately.                                                                            |
| Interruptibility     | Immediate frequent actions have no queued exits. Reader navigation retains the mounted Sheet. Completion pulses cancel on revision cleanup/unmount.                                                                     |
| Performance          | No per-frame React state or speculative GPU hints. Tablecn brings its required DnD dependencies; the Sheet retains its installed blur; divided footer pagination needs no backdrop blur. Frame cost remains unmeasured. |
| Accessibility        | Reduced motion uses an undelayed 120ms content fade with no translation. Focus reveals its group immediately. Completion opacity minimum remains 0.85 for the declared light-pair contrast of 4.89:1.                   |
| Cohesion/tokens      | Reader and content share one easing token and the installed Sheet opening state. Filter/sort menus retain keyboard operation on their single drag handle, without extra move buttons.                                   |
| Missed opportunities | The requested reader content stagger is implemented for panel opening. Frequent navigation and query updates stay immediate.                                                                                            |

Rejected additive candidates: selection dock (frequent state changes), Previous/Next reader navigation (frequency and reading function), property command pages (keyboard input), Dashboard count-up (obscures values), and empty-state staggering (no functional purpose). Reader entry provides spatial context for the new overlay. Its heading/actions, facts and description rise 8px into place on opening, including skeleton groups. Subsequent posting changes and late query results stay immediate. The controlled Sheet starts closed and opens on the next animation frame so Base UI runs its native entrance; the scheduled frame cancels on cleanup. There is no per-frame React state.

Original generated-CSS and pulse checks passed. Earlier full-suite evidence is recorded in [the code review](../plans/code-review.md); current reader checks are recorded in [the collection follow-up](../plans/004-collection-controls.md). Frame timing, pointer feel, mobile behavior, slow-motion replay, and rendered layout were not verified in a browser.
