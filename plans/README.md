## Motion decisions

No additive animation passed all four gates: frequency, purpose, speed, and function. Selection/dock, reader/list navigation, and property command pages are frequent or keyboard-driven; Dashboard count-up obstructs reading data; an empty-state stagger has no functional purpose. Keep them immediate. Preserve standard anchored popup feedback, reduced-motion suppression, loading indicators, and the intentional 180ms refresh-completion pulse with safer contrast. No Motion dependency, gesture work, or per-frame React updates introduced.
